Downloader sign-in

rule34video allows one session per account. This shares the session Chrome already has with the Downloader app (open on this PC), so neither gets signed out.

Discord: with discord.com open (signed in) in a tab, this sends that account's token, so you don't have to copy it from DevTools.

X/Twitter: sends the x.com sign-in Chrome has. No cookies.txt to export.

Bluesky: with bsky.app open (signed in) in a tab, the app makes its own app password from that session. Chrome stays signed in.
