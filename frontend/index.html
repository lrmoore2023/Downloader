Token type
Downloads media from a specific channel (paste its URL in Configure Links). Get a user token from your browser:
  1. Log in at discord.com, press F12 → Network tab.
  2. Type messages in the filter, then click any channel.
  3. Click the messages request → Headers → copy the authorization value.
  4. Paste it above; set type to User account.
Read-only (never posts), but automating a user account breaks Discord's ToS — prefer a secondary account for servers you don't own. Bot token: only for servers you can add a bot to (create at discord.com/developers, enable the Message Content intent).
Pawchive
Concurrency 6 downloads at once
Pawchive simultaneous downloads. Its CDN caps each connection's speed, so more parallel downloads = faster overall (~6 is the sweet spot). Lower it only if you see repeated rate-limit blocks.
Auto-extract
After a pack downloads, sort its images into Images/<year> and videos into <year> (named like your other files); any other files are kept together in a folder named after the archive. The original archive is deleted once extracted.
Cloudflare access Checking…
Pawchive now sits behind a Cloudflare check that blocks the app. Click Connect — a small window opens, clears the check automatically (usually a second or two), and the app remembers it. If a fetch later fails with a Cloudflare message, just click Reconnect.
Pawchive Link Filters
Hide junk from the “Links needing attention” list. Enter a domain (youtube.com — also matches subdomains), a subdomain prefix ending in a dot (shop.), or part of a URL containing a slash (patreon.com/posts/ hides paywalled posts but keeps profiles). Changes apply immediately — no re-download needed.
